## English (r/FlutterDev, X/Twitter thread opener)

**Title**: I built fluFrame — production-ready Flutter apps in one
command (Riverpod 3, go_router, auth incl. Supabase/Firebase wiring,
i18n, tests already green)

**Body**:

Starting a Flutter app always meant a day of wiring the same things:
state management, routing, theming, localization, storage, auth, lints,
tests. I got tired of it and built **fluFrame**.

```sh
dart pub global activate fluframe
fluframe create my_app --org com.mycompany --backend supabase
cd my_app && flutter run --dart-define-from-file=env/dev.json
```

What you get, already wired and passing 53 tests:

- **Riverpod 3** (manual notifiers, no provider codegen) + **go_router 17**
  bottom tabs with nested routes
- **Auth scaffold**: email/password login, gated profile tab with
  return-path redirects, persisted session — backend-neutral behind one
  `AuthRepository` seam. `--backend supabase` or `--backend firebase`
  wires the real SDK for you (or keep the offline fake)
- **Localization** (en/ko), **Material 3 theming** with 5 persisted color
  presets + dark mode, **offline fallback cache** for the REST sample,
  flavors via `--dart-define-from-file`
- **very_good_analysis with zero issues**, freezed models, dio with typed
  error mapping
- Every generated variant is e2e-tested in CI: the generated app itself
  passes `flutter analyze` and `flutter test` before any release ships

pub.dev score is 160/160. The repo also documents its own development
process (ADRs, design specs, retros) if you're into that.

Links: https://pub.dev/packages/fluframe ·
https://github.com/JoGyoungJun/fluFrame

It's young (0.8.0) and I'd genuinely love feedback — what would you
need before using something like this for a real project? Issues and
PRs very welcome.

## 한국어 (커뮤니티용)

**제목**: 명령 한 줄로 프로덕션 수준 Flutter 앱을 만드는 fluFrame을
만들었습니다 (Riverpod 3 · go_router · Supabase/Firebase 인증 ·
다국어 · 테스트 올그린)

**본문**:

Flutter 프로젝트를 시작할 때마다 상태관리, 라우팅, 테마, 다국어, 저장소,
인증, lint, 테스트를 똑같이 다시 엮는 데 하루씩 쓰는 게 지겨워서
**fluFrame**을 만들었습니다.

```sh
dart pub global activate fluframe
fluframe create my_app --org com.mycompany --backend supabase
cd my_app && flutter run --dart-define-from-file=env/dev.json
```

생성 직후부터 53개 테스트가 전부 통과하는 상태로 다음이 포함됩니다:

- **Riverpod 3**(수동 노티파이어, 코드젠 없음) + **go_router 17** 하단
  탭·중첩 라우트
- **인증 스캐폴드**: 이메일 로그인, 복귀 경로를 기억하는 게이트 라우팅,
  재시작해도 유지되는 세션 — `AuthRepository` 하나만 바꾸면 백엔드 교체.
  `--backend supabase` / `--backend firebase`로 실제 SDK 연결까지 자동
- **다국어(en/ko)**, 다크모드 + **영속화되는 테마 색상 프리셋 5종**,
  REST 샘플의 **오프라인 폴백 캐시**, `--dart-define-from-file` 플레이버
- **very_good_analysis 경고 0건**, freezed 모델, 타입 매핑된 dio 에러 처리
- 모든 생성 변형이 CI에서 e2e 검증됩니다 — 생성된 앱 자체가 analyze/test를
  통과해야 릴리스가 나갑니다

pub.dev 점수 160/160 만점입니다. 저장소에는 ADR·설계 스펙·회고 등 개발
과정 문서도 공개되어 있습니다.
