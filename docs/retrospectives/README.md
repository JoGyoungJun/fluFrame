# Retrospectives

One retrospective per closed milestone, produced by the `/retro` skill:
plan-vs-actual from GitHub data, OSS adoption metrics, follow-up on the
previous retro's action items, and 3-5 new action items (each with an
owner and a deadline) that feed the next milestone plan.

Files are named `YYYY-MM-<milestone-slug>.md`. Keeping them public is
deliberate — contributors can see how the project learns.
