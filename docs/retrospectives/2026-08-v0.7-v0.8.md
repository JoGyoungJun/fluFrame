## Incident: 0.7.0 shipped without its feature

The release branch was cut while feature PR #49 was still OPEN — its
auto-merge was silently stuck BEHIND main under the strict up-to-date
requirement, and the release script proceeded on green checks alone.
0.7.0's changelog therefore described a feature the package did not
contain.

**Resolution**: `gh pr update-branch` un-stuck #49; 0.7.1 shipped the
presets with a changelog that marks 0.7.0 honestly.
**Prevention (already landed, PR #52)**: `/cycle` and `/release` now
require polling `gh pr view --json state` for MERGED — green checks are
not merged — and document `update-branch` for stuck PRs. The rule
proved itself the same hour: PR #54 hit the identical BEHIND state and
was resolved by the book.
